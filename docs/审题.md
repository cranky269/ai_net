思路:
1. 核心：在DroneRFb-DIR数据集（同时需要设置4档信噪比），体会不同信号预处理算法（中值，维纳，谱减等，均作用于IQ时域序列，操作时参考调研文献的预处理流程）对于CNN的识别效果的影响，从背景噪声抑制和有用特征丧失这个trade off去解释效果的影响（STFT时频图在预处理之后生成）。



实现流程：
1. CNN网络一条龙实现（数据集读取拆分训练评估），实现一定量的“上限精度”（即无预处理、无噪声下的精度），仅作sanity check、验证网络本身具备完成识别任务的能力，不纳入任何对照组。固定随机种子和训练步骤--》绘制“验证准确率~训练轮数”的曲线。

   对照体系（全局约定）： 加噪+不预处理(真正基准) / 加噪+预处理(各方法)。所有“预处理是否有效”的结论均与“加噪+不预处理”基准比较，而非与无噪声上限比较。

2. 预处理算法筛选：实现≥10种预处理算法--》从中挑出6种具有不同影响曲线的算法（筛选池）--》再从中留2~3种便于从背景噪声抑制与特征损失解释曲线的算法作为论文主线，其余均为筛选过程（不进论文），详情见“疑惑Q3”。

3. 找到合适的背景噪声抑制衡量参数和时频特征衡量参数来解释2的曲线（量化指标待数据出来后选定，不预设具体指标）
   
4. 总结结论，书写论文。

Q3：预处理算法选择什么样的？（⭐）

A3：选择可以比较好验证结论的预处理算法，即可以验证“预处理算法不一定既可以剔除背景噪声来实现更高精度，但同时也会因为特征抑制而导致精度下降，对精度提升不一定是正相关”---》找到不同强度下，具有不同影响曲线（验证准确率~处理强度）的预处理算法，比如在给定信噪比条件下（很低，一般低，较低，正常），恒上升趋势，恒下降趋势，先快上升后缓上升趋势，先上升后下降的趋势，或者在不同信噪比下预处理算法的验证~处理强度横向曲线不一致（有些在低信噪比的作用比较好，有些不行之类的）
--》需要提前实现较多的预处理算法来做筛选（≥10种）

论文逻辑：
1. 分析相关的论文2篇--》需要找满足什么条件的论文才比较合适？
2. 分析待处理的数据集（读取，以原始记录为单位划分数据集，STFT频谱生成和简要分析）；注意：先按原始记录分组划分训练/验证/测试集，再在各集合内分别加噪，避免同一记录的不同片段或噪声版本跨集合泄漏。
3. 4种程度的加噪（对应于4种信噪比），说明产生的一些可见变化（时域，频域，特征数值等等），分析加噪带来的问题。
4. 使用2~3种预处理算法（1种经典+1种文献复现，必要时再+1种），按照参考的调研文献进行复现，比较使用后对数据产生的影响（背景噪声抑制和部分特征损失两方面说明）。其中刻意保留1种“代价型”算法（先升后降/下降曲线），作为“特征损失导致精度下降”这一半论点的实证。
5. CNN网络搭建，比较无预处理算法，有预处理算法（4中的2~3种）对于识别结果的影响---》分类准确率、Macro-F1及混淆矩阵，记录预处理耗时。归因到4提出的背景噪声抑制和部分特征损失上去。
6. 进一步验证，单独拿出某一种预处理算法（可调参数较多的），设置3种处理强度，分析不同强度下背景噪声抑制和部分特征损失的变化，以及CNN的识别性能--》再次验证背景噪声抑制和部分特征损失的影响。
7. 横向比较不同预处理算法的优势，局限性和适用条件（重点从背景抑制和部分特征损失上靠），凝练关于“时频图的视觉清晰程度与CNN分类性能之间的关系”的结论。
