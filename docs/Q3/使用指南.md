# Q3 使用指南

## 可调参数和不可调的参数
- 数据集可调的参数（只能调这些）：hop_ratio，每张图的帧数（frames_per_image），是否重采样（bg_resample，对于背景），精度（dtype）
- 数据集固定的参数：帧长为2048，信号统一取前面的50ms

- 模型可调的：模型架构（yaml文件，arch），预训练权重（pt格式，weights），训练配置（batch（batch_size），epochs，学习率（lr），学习率调整策略（可自己加），反向计算策略（可自己加或调整）等,训练设备（device，选择gpu的话，需要自己额外加代码）），一些超参数（weight_decay）

- 模型固定的：统一使用测试集而不额外使用验证集来保存最佳参数

- 其余可调的：随机种子（在stage2的config里面，init和loader）

## 注意
stage_1 和 stage_2 的 config 里都有 dtype、db_floor、cache_dir，两边必须一致，否则归一化方式与缓存精度对不上，训练直接失效。这是最值得写进指南的一条


## 训练流程：
0. 下载依赖（requirement.txt）
1. 数据集准备
  - 将python\Q3\stage_1\config.json中的“max_per_class”配置赋值0，使得可以缓存所有的训练集和测试集
  - 数据集可调参数配置
  - 执行“python python/Q3/stage_1/build_cache.py”
2. 模型配置
    - 模型可调参数配置
    - 随机种子配置
    - 执行“python python/Q3/stage_2/train.py”
3. 模型训练和参数保存
